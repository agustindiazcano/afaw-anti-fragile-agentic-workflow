## Project Overview
Anti-Fragile Agentic Workflow (AFAW) is an adaptive, resilient multi-agent framework designed to handle complex automated engineering tasks.

## Workflow Principles
- **Anti-Fragility**: Systems adapt, self-correct, and improve from errors and edge cases.
- **Modularity**: Agents and configurations are organized into discrete directories (`agents/`, `gemini/`, etc.).
- **Clear Contracts**: Communication between agent nodes follows structured interfaces.
