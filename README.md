# Anti-Fragile Agentic Workflow (AFAW)

An anti-fragile, multi-agent workflow framework designed for resilient, adaptive AI-driven software engineering and automation.

## Project Structure

- `agents/`: Agent definitions, prompts, and orchestration logic.
- `gemini/`: Configurations and integrations for Google Gemini models and workflows.
- `CLAUDE.md`: Guidelines and context for Claude agent interactions.
